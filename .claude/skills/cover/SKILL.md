# cover：封面

合成时会自动画两版封面：A 版用标题做大字，B 版用带数字的钩子做大字、标题做副标。同时还会排出 3:4 和 4:3 两种比例。车图优先用素材池的白底官图抠图；抠不出来就生一台车（会标注"AI 生成示意"），再不行就退回老封面。

```bash
python -m app.cli cover <pid>                       # 封面路径、可选标题、当前选择
python -m app.cli cover-rebuild <pid> [--title 1]   # 换用第 1 条标题(package 里的下标),重画 A/B
```
用 Read 看两张封面，再交给用户挑。

## 自审清单
- **大字在手机缩略图上能不能一眼读完**：A 版大字最多两行，B 版钩子 8 字以内。
- 车名对不对、是不是完整车名，数字是不是和事实一字不差（钩子来自包装标题里的数字）。
- 车图：是不是这台车（年款、外观对不对），有没有车牌和水印残留，AI 生成的车有没有明显畸形（轮子、车灯）。
- 主页一排看过去风格要统一，不要单独给这一期换版式。
- 字压到车头、或者车太小时：先换标题（`--title`），还不行再用 `package-put` 改标题文案。版式本身是统一风格，不在单片里改。
- 退回老封面会记一条降级（`/api/degradations` 的 `cover.*`），要告诉用户。
