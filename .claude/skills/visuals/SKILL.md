# visuals：生图

```bash
python -m app.cli image "<提示词>" --project <pid> --n 2 --ratio 16:9
python -m app.cli image "<提示词>" --out <目录> --ratio 3:4    # 不挂项目
```
图片存进 `<项目>/images/`，提示词另存一份 `.prompt.txt`。生成结果用 Read 看图挑选。每次调用都记进账本（kind=image），每张图都要花额度，一次 2 张就够了。

## 提示词怎么写
- 结构：主体 → 视角和构图 → 光线 → 背景 → 风格 → 画幅留白。例如：`"银色中型 SUV 正侧面，白色无缝影棚，柔和顶光与地面反射，画面左侧三分之一留白放文字，商业汽车摄影，高清锐利"`。
- **不要让模型画字**：图里的文字一律后期叠加。提示词里要写"无文字、无车标、无水印"。
- **不要冒充真车实拍**：生出来的车是"示意"，封面会自动标注"AI 生成示意"。要准确的外观就用素材池里的官图（封面流程会优先用官图抠图）。
- 概念示意（剖视、爆炸图、能量流）：写清楚部件和视角，例如"剖视""等轴测""线稿 + 局部发光"，风格要和片子的视觉包一致。
- 不满意时**一次只改一个变量**（构图、光线或风格），这样才知道是哪一项起了作用。

## 用在哪
- 封面：见 cover skill（封面流程自己会选车图，生图主要用来做背景或补位）。
- 概念动画：生成的图放进项目 `images/`。目前项目片段只能引用 shell 提供的文件，用生成图做底要另外接线，先跟用户确认是否需要。
