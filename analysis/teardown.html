01 · 定位

别在「参数面板」这条赛道上卷

「三驱兄弟」那批号已经把「宣传片铺底 + 左侧参数面板 + 底部章节条」做成了这个品类的视觉惯例。 你现在的产线几乎逐帧复刻了这套语言——这在早期是捷径，现在成了天花板：越像他，越不会被记住。

维度满屏的 AI 参数解说号你手上已经有、但没亮出来的
视觉 同一套左参数面板 + 底部章节条 概念动画（电池包 / 加速表 / 尺寸线稿 / 激光雷达）+ HUD 版式——bakeoff B/C 的完成度比现有叠加层高一个维度
数据 数字直接写，不给来源，错了也没人管 事实可追溯：fact_refs 强制引用 + cards.ground 逐行核对 + verify_number_grounding
结论 参数罗列，念完就忘 观点前置已经生效（"先给结论""标准版闭眼入"），可以再往前推一步做冲突式钩子
合规 靠人自查，夸大用语过不了审 机械 lint：绝对化用语、编造数据、贬低竞品、层级混用全部拦下——这是接商单和投流的准入证

一句话结论：你缺的不是更多版式，是把「我能证明的东西」摆到台面上。 别人在拼画面数量，你在拼证据密度——这才是 AI 号短期内抄不走的。

02 · 诊断

三个致命问题，按影响排序

2.1　素材：200 段视频里，能直接用的只有 3 段

标签口径：problem 为空即「干净」（无烧录字幕／台标／海报／非车）， target=="yes" 即「视觉模型确认是这台车」。

这 3 段分别是 航拍 ×2 和 车尾 ×1——内饰干净视频是 0 段。所以成片里「内饰空间」章节只能靠一张静图撑住。

官方号反而没被用起来：小米汽车 B 站 20 段只干净 3 段，Xiaomi 官方 YouTube 36 段里 「干净且确认是本车」是 0 段——官方片里的产品特写、其它车系、人物被标成了 no_subject 或 unknown。 素材池的问题不在「搜得少」，在「筛得狠」和「标签判得太死」。

代价是双重的：成片右上角的「CCTV 1 综合」台标、右下角的「黄金展位 制作机构」角标、 以及航拍镜头上方的「Soda' bilibili」水印，都是这 197 段素材的代价。 它不只是难看——是在二次转载别人的视频做商业内容。这是比观感更硬的问题。

2.2　画面和旁白各走各的

README 里那句「不要求画面对上旁白」，是这套产线早期最快的捷径，也是现在最明显的天花板。 素材池明明打好了 9 种视角标签（exterior_45 / interior / driving / screen / detail / seat / aerial / rear / exterior_front）， 但分镜只用 sec.angle 里的两档去取景——「偏外观」和「偏车内」。

实际发生的：讲「风阻系数 0.245Cd，高速省电」时，画面是一个无关的内饰特写； 讲「GT 版 1003 匹」时，画面是静态官图。 观众的感觉不是「这视频糊弄」，是「这视频跟我想买的那台车没关系」。

改法很轻：把这一拍讲的东西映射到具体 view（讲电池 → detail， 讲加速 → driving，讲智驾 → screen）， 取景时按 view 检索而不是按角度档位。标签已经在库里了，只是没接上。

2.3　字幕里的数字，全变成了中文

这条最扎眼，也最好修。TTS 用的中文读法被复用成了字幕文本—— 旁白读得对，但屏幕上打出来的全是「六百四十三公里」。而你的画面上同时写着「835 公里」「38.99 万元」。

应该是
标准版 73 度磷酸铁锂，CLTC 续航 643 公里
它用 752V 碳化硅高压平台，15 分钟补能 405 公里
想要性能，GT 版 1003 匹马力，零百 3.93 秒，最高时速 300
成片实际
标准版 七十三 度磷酸铁锂，CLTC 续航 六百四十三 公里
它用 七百五十二 伏碳化硅高压平台，十五 分钟补能 四百零五 公里
想要性能，GT 版 一千零三 匹马力，零百 三点九三 秒，最高时速 三百

根因：一份文本同时喂给了 TTS 和字幕。

# app/pipeline/narration.py
texts = [normalize_for_tts(t) for t, _ in pairs]   :110  ← TTS 专用（中文读法）
used_texts = [texts[i] for i in order]              :168
cues = build_subtitle_cues(used_texts, ...)                 :184  ← 字幕复用了它

修法是一行：字幕改用原始文本（pairs[i][0]），TTS 继续用归一化文本。 顺带的好处是 kWh、km/h 这些行业符号也留在屏幕上，而不是变成「千瓦时」「公里每小时」。

为什么这条排在最前面：汽车视频的一切都建立在数字上。 字幕全变中文之后，观众没法扫读、没法截图、没法在评论区引用， 而画面上的大字又和你自己的字幕对不上——这会让人怀疑整条片子是 AI 拼的。

三条你已经有了、但还没摆到台面上的东西

事实可追溯 —— 把「每个数字都能查」变成可见的卖点

现在这行「数据来源：公开信息与官方渠道 · 2026-10」在面板角落，20px 灰字，手机上基本看不见。 但它是你唯一无法被模仿的能力——参数号编数字，你每个数字都有 fact_id 和来源工具。 把它做成显式设计：数字旁边标「官方 / 媒体 / 实测」，标年份与版本，把「我们不编数据」变成片子的信任状。

04 · 留存

「让别人更喜欢看」：三件具体的事

开头 15 秒该发生什么

  1. 0–3 秒：先给冲突，不是先给结论当前：分屏小窗 + 大字

    现在是「小米YU7 值不值得买」——一个正确但平的问题标题。 换成一句带判断的冲突：「这车最贵的地方不是配置，是它的电池」，观众才会想往下看。

  2. 3–10 秒：立刻兑现承诺当前：环境镜头空转

    承诺了「三个数决定你买不买」，就要在 10 秒内把第一个数拍在脸上。 首屏必须出现一个大数字或大字，而不是让人等背景音乐铺满。

  3. 10–15 秒：建立可信度当前：只有一行 20px 灰字

    把「每个数字都可追溯」在这里亮一次——这是全片唯一一次「自我担保」的位置， 说完就恢复正常解说。

  4. 结尾：给行动，不只给总结当前：标准版闭眼入

    现在结尾停在「标准版闭眼入」，没有下一步。 补一句提问（你在纠结哪台？评论区说车型，我下期做横评）或下期预告—— 评论区互动和连看都靠这一句。

建议加一条硬约束：每 5–6 秒必须有一次画面变化（换镜头 / 换版式 / 进大字 / 进动画）， 且全片 broll 占比从四成压到三成以内，腾出来的位置给 concept 和 stat。

06 · 包装

封面：现在抽的是最不该抽的那一帧

make_cover() 固定从第 1.0 秒抽帧——而第 1 秒恰好是开场的黑底分屏小窗， 构图是「中间一个小方块 + 四周黑边」，作为封面几乎是最差选择。标题还按 title[:14] 硬切， 「小米YU7值不值得买，该怎么选」会被切掉最后一个字。

建议：抽帧改为「扫描全片选构图最完整且有全车的一帧」，或专门渲染一张封面帧（大字 + 全车 45° + 一个爆点数字）； 标题改成自适应缩排而不是硬截断。
