# 抖音流量规则(第二轮:官方原文,2026-10-24)

来源全部是抖音官方页面,标 [官方]。第三方营销文章里的"权重百分比""完播率 40% 晋级"等没有官方依据,不采信。

官方来源:
- 安全与信任中心 https://95152.douyin.com :算法原理 article/15358、原创规则 article/15179、优质内容 article/15360、社区自律公约 article/15175(2025-01-20 版)
- 《抖音用户服务协议》(更新 2026-02-13,生效 2026-02-20)4.5 条
- 抖音电商创作者管理总则(2024-01-18 修订,内容红线部分可参考,我们不带货时不适用)

## 1. 推荐机制 [官方]
- 一条新视频:先**初步评估进入内容池 → 召回(双塔模型粗筛)→ 排序**。
- 模型预测的是用户"是否会看完 / 点赞 / 收藏"等行为概率;官方未公布各指标权重。
- 算法"不理解内容语义",靠用户行为向量匹配 → 前几秒留不住人、完播差,后续就没有量。
- 官方没有"养号"、"流量池分级晋级"的说法;这些是第三方经验词。
- 对本项目的含义:不要预设权重;让 coach 用自家 completion_rate / bounce_rate_2s 去验证。

## 2. 对长内容/深度内容的态度 [官方]
- 优质内容 = 合规 + 画面/信息价值达标,具备"获得感、惊喜感、表达力、感染力";**优质不等于流量好或成本高**。
- 优质内容有"专门的分发推荐方式";抖音精选(中长视频)、每周精选内容有流量扶持,入计划作者稿均播放 +12%、涨粉 +17%(官方统计)。
- 官方明确提到长内容、深度内容在抖音数据亮眼(举例 240 分钟视频)。
- 对本项目:横屏 2–8 分钟讲解有官方支持的土壤,不必为了推荐硬做短竖屏;"获得感"= 信息增益,与我们的事实/口径路线一致。

## 3. 原创性(**对本项目最关键**) [官方]
- 不建议:站外非本人素材直接用,或"简单加工"(仅加特效、转场、配乐、文字、一句话解说)。
- 建议:不侵权前提下加**内容增量**——背景解读/延展科普("深度解读")、重构叙事、多素材提炼总结(榜单/合集)。
- 不建议:画面带他人水印号或用马赛克遮水印;转载即使有授权也不算原创;注明原作者也不算原创。
- 相同/相似素材只在一个抖音账号发布;同账号重复投稿暂不判非原创但不建议。
- 对本项目:官方图/B 站素材只当松散背景、信息由我们的口径/卡片/概念动画承载,方向正确;风险点是 (a) 非官方素材带水印被裁边但仍带他人画面 (b) 分发官的 clip 与主片素材高度重合,同账号重复投稿。

## 4. 红线 [官方]
- AI 标识(用户协议 4.5):用深度学习/生成式 AI 制作的**非真实音视频**或可能致公众混淆的内容,发布时应**以显著方式标识**;平台可在内容周边加提示。细则见《抖音关于升级AI内容标识功能的公告》(原文未取到;媒体转述:发布页「高级设置→内容自主声明」,未声明时平台可能加"疑似使用了AI生成技术"或"作品含AI生成内容"标识)。
- 不实信息(公约 21):没事实依据编造、断章取义、拼凑剪接、刻意夸大。→ 与 grounding / 数字必须有事实支撑一致。
- 不当营销与虚假宣传(公约 33):对性能/功能/质量做虚假或误导宣传;对安全性能无合理依据的断言;把科学未定论当定论;标题党、炒作负面、引战。→ 汽车类"最强/最安全/吊打"之类要避免。
- 电商总则 4.2.3/4.2.5(参考):不用"国家级/最高级/最佳"等极限词;不恶意比较、贬损第三方。
- 危险驾驶(公约 12):违规追逐竞驶、违规超车、醉驾等。→ 素材里的赛道/加速画面注意不要是公路竞速。
- 知识产权(公约 25):未经许可使用他人影音作品;背景音乐需授权(电商总则 4.3.3)。→ BGM 现用 Mixkit 免费商用,OK。
- **自动化(公约 32)**:"未经平台允许,采用自动化手段或明显异于常人的、远高于正常用户频率地…发布视频、评论、私信、关注、点赞、**抓取数据**"属违规。
  - 对本项目:发布官(浏览器自动化发布)、运营官(自动回复评论)、分析官/对标官(抓创作者中心与对标主页数据)都落在这条的灰区。官方未给频率阈值。
  - 应对:保持"像真人"的低频(每日发布 ≤1–2 条、回复有间隔与上限、抓取间隔拉长)、回复默认人工批准(已是默认)、不并发多账号。
- 账号(公约 36):禁止买卖/租借账号、批量注册;封禁后以相似信息重注册也违规。

## 落地建议(按优先级,待你定)
1. 发布流程补"内容自主声明:AI 生成"勾选 + compliance 清单加一项(当前代码里没有)。
2. compliance 加原创性检查:主片中"非本人素材"占比/连续时长(explainer.footage_mix 已有数据),过高标红;分发官 clip 与主片重合度提示。
3. 节奏护栏:publisher 每日发布上限、运营官回复/抓取频率上限与随机间隔,写进 team settings(默认保守)。
4. 极限词/贬损比较词表并入 compliance(汽车类:最强、最好、第一、吊打、碾压、秒杀…)。
5. 其余"怎么涨量"类假设(发布时间、标题结构、话题数)官方没有答案,交给 coach experiments 用数据验证。
